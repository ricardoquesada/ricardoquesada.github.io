I'm learning knitting, not sure for how long I'll keep it up, but this is my "Hello World" project, a kind-of scarf.

I wanted to do a scarf, but I run out of wool, so I created a "small" scarf, which in spanish is called "cuello", but I don't know the english word.

![cuello](/images/knitting_hello_world_full.jpg)

It uses mostly Jersey stitches, but every some rows I did a "knit-knit-purl-purl" stitch (I don't know the name of that stitch).
